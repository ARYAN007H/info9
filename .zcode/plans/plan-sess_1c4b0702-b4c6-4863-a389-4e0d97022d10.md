# info9 GUI redesign — "Evidence Bench" (branch `gui-improvement`)

## Context
info9's UI is currently a generic SaaS kit: slate surfaces, sky-600 buttons, a stack of rounded-xl white cards, one radius on everything, sky accent inflated across every element. For an evidence-first OSINT workbench whose differentiator is provenance (LIVE / DERIVED / NO-DATA chips, SHA-256 hash-chained ledger), the interface should read as a precision instrument, not a template. The redesign also fixes real UX gaps: no persistent case context, the evidence ledger buried inside the sanctions module, a centered 1240px column that wastes a dense tool's viewport, brand split ("Argon OSINT" header vs info9 repo), and 4× copy-pasted tab switchers / 5× notice banners / ad-hoc inputs.

**Chosen direction (user-approved):** Evidence Bench — night-lab graphite + a single signal-orange accent reserved for active state / primary CTA / ledger seal; ruled instrument panels; Archivo (UI + expanded signage display) + Spline Sans Mono (all data values). Both modes kept, dark default. One orchestrated motion moment; everything else disciplined.

## Design system

**Tokens** (CSS vars under `:root` / `.dark`, mapped in Tailwind v4 `@theme inline` so `bg-panel text-ink-2 border-line` etc. work in both modes):

| role | dark (default) | light |
|---|---|---|
| app bg | `#0E1113` | `#EDEEEC` (cool concrete — deliberately not warm cream) |
| panel | `#14181B` | `#F8F8F6` |
| raised / inset well | `#1A1F23` | `#FFFFFF` |
| line / strong | `#272E33` / `#39424A` | `#D3D7D4` / `#BFC5C1` |
| text primary/secondary/muted | `#E9EDEE` / `#9FAAB2` / `#6B767E` | `#1B2224` / `#525D61` / `#7C868A` |
| accent (evidence orange) | `#FF6B2C` (hover `#FF8350`, on-accent `#171009`) | `#DE4E00` (on-accent `#FFF7F2`) |
| provenance LIVE / DERIVED / GAP | `#3ECF8E` / `#6FB7FF` / `#E5B454` | `#0E8A5F` / `#1D6FBF` / `#9A6B00` |
| danger | `#F26D7E` | `#C4324A` |

**Type:** Archivo (variable) — body/UI 13–14px, panel titles 15px/600, wordmark + equipment tags in expanded width (font-stretch ~125%) as the signage voice; Spline Sans Mono — every data value (coords, hashes, IPs, scores, timestamps), 12–12.5px, tabular. Sentence case everywhere; caps only on the wordmark descriptor + equipment tags. Fonts swap in `index.html` (replace Plus Jakarta/Public Sans/JetBrains Mono).

**Radius/hairlines:** 6px panels, 4px chips/inputs, 1px hairline borders, inset wells on `raised`. No shadows except the command palette + drawer.

**Layout — "the bench":**
```
┌──────────────────────────────────────────────────────────────────┐
│ ■ info9 ARGON WORKBENCH      3 LIVE · 1 DERIVED · 1 GAP [Search ⌘K]│ 56px instrument strip
├─────────────┬────────────────────────────────────────────────────┤
│ CASE SPINE  │  01 · GEOLOCATE ──────────────────── [primary CTA]  │ module header plate
│ MY-WORKSPACE│  ┌ inputs (5 col) ┐ ┌ map / results (7 col) ─────┐  │
│ OPEN SOURCE │  └────────────────┘ └────────────────────────────┘  │
│ RESEARCH    │                                                    │
│ 01 GEOLOCATE│                                                    │
│ 02 DOSSIER  │                                                    │
│ …+ tallies  ├────────────────────────────────────────────────────┤
│ theme/reset │ ▲ EVIDENCE LEDGER · 4 ENTRIES · CHAIN VERIFIED …    │ collapsible drawer
└─────────────┴────────────────────────────────────────────────────┘
```
- **Case spine (new, ~240px left rail):** case identity plate (codeName mono, classification, updated UTC), module index 01–05 with live tallies, case-wide provenance tally, theme + reset at bottom. Collapses to a horizontal scroll rail < 1024px.
- **Evidence drawer (new, bottom):** the hash-chained ledger always one click away — chain-integrity chip, mono ledger rows (index · UTC · module tag · target · finding · hash fragment), "Export case report (.md)". Export/reset banners become a small toast.
- **Module header plate:** equipment tag (01–05, matches README catalogue) + module name + one-line job description + primary action. No hero fluff.

**Motion:** single moment — panels resolve 140ms fade/4px rise on module switch (staggered ≤ 30ms), drawer slides 180ms; both disabled under `prefers-reduced-motion`. Global `:focus-visible` = 2px accent ring.

**Copy:** unify wordmark on "info9 · ARGON WORKBENCH" (matches docs/banner.svg). Buttons state the action ("Export case report", "Reset workspace" + confirm, "Run intersection", "Screen name"). Empty states direct the next action ("Nothing scanned yet — enter a domain above…"). Notices say what happened + how to fix. Provenance chip wording (LIVE/DERIVED/NO DATA) stays.
